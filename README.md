## Contexte

- Mini projet réalisé par curiosité pour prendre en main VueJS 
- Projet initialisé avec Vite, j'ai utilisé PicoCSS pour le style le but étant de découvrir VueJS avec un petit projet j'aimerais revenir plus tard dessus peut-être en utilisant tailwindCSS et faire en sorte de sauvegarder la todo list en local ou sur une BDD 

## Structure du projet :

- Un dossier src qui contient un fichier Compteur.vue ( à servis à prendre en main les fonctionnalité de base de VueJS ) .
- Un fichier App.vue qui contient une todo list avec deux valeur en brut.
- Un fichier CSS

## Technologie utilisé

- VueJS
- Vite
- PicoCSS
